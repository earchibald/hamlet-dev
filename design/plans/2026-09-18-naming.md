# Names: the land, the camps, the events, and the people — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the valley, its landmarks, its camps, its events, and its people names with a history, without moving one being or one item on any seed.

**Architecture:** One new file, `src/sim/names.js`, loaded after `core.js` and before `world.js`. It owns the record shape, a second random stream salted `:names`, the syllable and word tables, the namer, the epithet scorer, and the mythos builder. `nameTheLand()` is a standalone function that `startWorld` calls after `generate()` returns. The old call sites stay thin: `camps.js` calls the camp moments, `tasks.js` calls the sector moment, `beings.js` learns old names where a person stands, and one nightly pass at the end of `updateCamps` names events and epithets. The interface reads the records; it never writes them.

**Tech Stack:** Plain JavaScript, no modules, no build step beyond `node build.js`. Node's built-in test runner. Safari through the Safari MCP for the visual check.

```js
/* ---------- names: the record, the second stream, and the old tongue ----------
   A name is a record. Every nameable thing keeps a list of records, newest
   first. The list never loses a record, so a chronicle line written under an
   old name can still be read back.

   Nothing in this file draws from the world stream `rng`. It has a stream of
   its own, seeded from the world seed with the salt ':names'. That is why the
   land, the beings, and the items of a seed never move when a name is given.
   Rules read the tables here. No rule reads name text. */
let nrng = null, mythos = null, tongue = null, valley = null, river = null, ponds = null, fords = null, nameIndex = null, usedMeanings = null;

function seedNames(){
  nrng = mulberry32(hashSeed(seedText + ':names'));
  tongue = null; mythos = null;
  nameIndex = new Map(); usedMeanings = new Set();
  valley = { names: [] };
  river = { names: [], tiles: [] };
  ponds = []; fords = [];
}
const nint = n => Math.floor(nrng() * n);
const npick = list => list[nint(list.length)];
function nshuffle(arr){ const a = arr.slice(); for (let i = a.length - 1; i > 0; i--){ const j = nint(i + 1); [a[i], a[j]] = [a[j], a[i]]; } return a; }
const cap = w => w[0].toUpperCase() + w.slice(1);
const titleCase = s => s.split(' ').map((w, i) => i === 0 && w === 'the' ? w : cap(w)).join(' ');

/* The record. `by` is the id of the being that named it, or 'lost' for the old tongue.
   `scores` is the candidate list the namer kept, as lastChoice keeps a decision. */
function nameRecord(text, o = {}){
  return { text, tongue: o.tongue || 'plain', meaning: o.meaning || '', since: tick,
    why: o.why || '', by: o.by === undefined ? 'lost' : o.by, scores: o.scores || null };
}
/* Give a thing a name. An old name starts unknown: somebody has to find the marks. */
function giveName(thing, rec){
  if (!thing.names) thing.names = [];
  thing.names.unshift(rec);
  nameIndex.set(rec.text.toLowerCase(), thing);
  if (rec.tongue === 'old'){ if (thing.nameKnown === undefined) thing.nameKnown = false; }
  else thing.nameKnown = true;
  return rec;
}
const nameOf = thing => thing && thing.names && thing.names.length ? thing.names[0].text : null;
const formerNames = thing => (thing && thing.names ? thing.names.slice(1) : []);
const nameTaken = text => nameIndex.has(String(text).toLowerCase());
function nameRecordOf(text){
  const key = String(text).toLowerCase(), thing = nameIndex.get(key);
  return thing ? (thing.names.find(r => r.text.toLowerCase() === key) || null) : null;
}
/* Everything that can hold a name, for the uniqueness check and the chronicle search. */
function nameThings(){
  return [valley, river, ...camps, ...sectors, ...hills, ...caves, ...groves, ...fords, ...ponds].filter(Boolean);
}

/* ---------- the old tongue ----------
   A syllable table is built from the name stream at generation. An old name is
   one or two words of one to three syllables. */
const OLD_ONSETS = ['v', 'k', 't', 'm', 's', 'r', 'n', 'l', 'th', 'sk', 'br', 'dr'];
const OLD_VOWELS = ['a', 'e', 'i', 'o', 'u'];
const OLD_CODAS = ['n', 'l', 'r', 's', 'k', 'm', 'sk', 'th'];
/* Pairs a mouth trips over. A syllable that would end in one drops its coda instead. */
const OLD_FORBID = [['sk', 'sk'], ['sk', 's'], ['sk', 'k'], ['th', 'th'], ['s', 'sk'], ['s', 's'], ['r', 'r'], ['l', 'l'], ['n', 'n'], ['m', 'm'], ['br', 'r'], ['dr', 'r'], ['t', 'th']];
function buildTongue(){
  return { onsets: nshuffle(OLD_ONSETS).slice(0, 8 + nint(5)), vowels: OLD_VOWELS.slice(), codas: nshuffle(OLD_CODAS).slice(0, 6 + nint(3)) };
}
function oldSyllable(){
  if (!tongue) tongue = buildTongue();
  const on = npick(tongue.onsets), v = npick(tongue.vowels);
  const coda = nrng() < 0.5 ? npick(tongue.codas) : '';
  return OLD_FORBID.some(([a, b]) => a === on && b === coda) ? on + v : on + v + coda;
}
function oldWord(){ let w = ''; for (let k = 0, n = 1 + nint(3); k < n; k++) w += oldSyllable(); return cap(w); }
function oldName(){ return nrng() < 0.35 ? `${oldWord()} ${oldWord()}` : oldWord(); }

/* What the old names mean. A meaning is never used twice in one world. */
const LAND_WORDS = [
  'the sleeping hill', 'where the water turns', 'the pines that watch', 'the stone that does not move',
  'the cold spring', 'the place of many birds', 'the long shadow', 'the first light',
  'the hollow under the rock', 'where the deer cross', 'the quiet ground', 'the wind from the north',
  'the black earth', 'the old fire', 'where the river forgets', 'the bones of the hill',
  'the bright water', 'the last tree', 'the low mist', 'the broken rim',
  'where the ice stays', 'the round stone', 'the deep dark', 'the loud water',
  'the bare crown', 'the green step', 'the hidden mouth', 'where the wolves sing',
  'the red clay', 'the thin path', 'the high seat', 'the wet hollow',
  'the still pool', 'the burnt slope', 'where the wind rests', 'the grey face',
  'the salt ground', 'the small light', 'the heavy rock', 'the last watch',
];
function takeMeaning(){
  const free = LAND_WORDS.filter(w => !usedMeanings.has(w));
  if (!free.length) return '';
  const w = npick(free); usedMeanings.add(w); return w;
}
/* One old name with its meaning, or null when the world has run out of either. A name with
   no meaning is not a name, so the meaning is taken first and given back on failure. */
function newOldName(why){
  const meaning = takeMeaning(); if (!meaning) return null;
  for (let k = 0; k < 10; k++){
    const text = oldName();
    if (!nameTaken(text)) return nameRecord(text, { tongue: 'old', meaning, why: why || `the old people called it ${meaning}` });
  }
  usedMeanings.delete(meaning); return null;
}
```

   A chronicle line whose tag is in this table, and whose kind is major, bad, or a

const EVENT_NAMES = {
  wolf:   { word: 'wolf',    phrase: 'the Night of the Wolf' },
  fire:   { word: 'ash',     phrase: 'the Night the Fire Ran' },
  frost:  { word: 'frost',   phrase: 'the Long Frost' },
  sprite: { word: 'light',   phrase: 'the Night of Lights' },
  found:  { word: 'parting', phrase: 'the Day They Left' },
  death:  { word: 'grave',   phrase: 'the Day We Lost One' },
  birth:  { word: 'cradle',  phrase: 'the Day a Child Came' },
};

const isEventLine = (e, c) => !!e.tag && !!EVENT_NAMES[e.tag] && EVENT_KINDS.includes(e.kind) && e.camp === c.id;
/* The camp's own events of the last 16 days, worth 20 and 3 a day of freshness. */
function eventCandidates(c){
  const out = [];
  if (!c) return out;
  for (const e of chronicle){
    const days = (tick - e.tick) / DAY;
    if (days > 16) continue;
    if (!isEventLine(e, c)) continue;
    const t = EVENT_NAMES[e.tag], recency = Math.round((16 - days) * 3 * 10) / 10;
    out.push({ text: t.phrase, axis: 'event', base: 20, recency, why: `for ${t.phrase}` });
    if (WORD_TAIL[t.word]) out.push({ text: cap(t.word) + WORD_TAIL[t.word], axis: 'event', base: 20, recency, why: `for the ${t.word} of that day` });
  }
  return out;
}

}

   An epithet is what others call you, so it is scored from the opinions others
   hold and from shared history. The camp is the namer, not a person, so no trait
   weight applies. An epithet is not a place, so it never joins the name index:
   two camps may both have a firekeeper. */
const DEED_EPITHETS = { fire: 'firekeeper', wolf: 'wolfdriver', found: 'founder', sprite: 'spritefriend', deer: 'deer-slayer', fish: 'fisher', pot: 'potter' };
const FATE_EPITHETS = { frost: 'the frozen', fire: 'the burnt', death: 'the lost', old: 'who died warm by the fire' };

function epithetCandidates(a){
  const out = [], folk = humans().filter(h => h.camp === a.camp && h !== a);
  let up = 0, down = 0, rivals = 0;
  for (const h of folk){

    if (op > 0) up += op; else down -= op;
    if (h.rel[a.id] === 'rival') rivals++;
  }
  if (up >= 40 && up > down) out.push({ text: 'the talker', score: 40 + Math.round(up / 10), why: 'people like talking to them' });
  if (down >= 40 && down > up) out.push({ text: 'the sour', score: 40 + Math.round(down / 10), why: 'arguments follow them' });
  if ((a.taught || 0) >= 5) out.push({ text: 'the teacher', score: 40 + a.taught, why: `taught ${a.taught} times by the fire` });
  if (rivals >= 3) out.push({ text: 'the one everyone argues with', score: 40 + rivals * 5, why: `${rivals} rivals in one camp` });
  /* Deeds, from the tags on the person's own history. */
  const tags = {};
  for (const e of a.history) if (e.tag) tags[e.tag] = (tags[e.tag] || 0) + 1;
  for (const k in DEED_EPITHETS) if (tags[k]) out.push({ text: DEED_EPITHETS[k], score: 30 + 5 * (tags[k] - 1), why: `for what they did, ${tags[k]} time${tags[k] > 1 ? 's' : ''}` });
  /* Life events and birth, from the lineage record. */
  const L = a.lineage || {};
  const kids = beings.filter(b => b.parents && b.parents.includes(a.id)).length;
  if (L.roof) out.push({ text: 'born under a roof', score: 20, why: 'born in a camp that had a roof' });
  if (kids >= 2) out.push({ text: 'twice a parent', score: 20 + kids, why: `${kids} children` });
  if (L.edge) out.push({ text: `walked in from the ${L.edge}`, score: 20, why: `came in from the ${L.edge}` });

  if (L.foundersChild) out.push({ text: 'child of founders', score: 20, why: 'both parents founded a camp' });
  if (L.firstBorn) out.push({ text: 'first born here', score: 20, why: 'the first child born in this camp' });

A thing keeps a list of records, newest first. The list never loses one, so a chronicle line written under an old name still reads. `src/sim/names.js` owns all of it, and is loaded after `core.js` and before `world.js`.

- **Two streams.** Names draw from a second generator, seeded from the world seed with the salt `:names`. The world stream is never touched, so the land, the beings, and the items of a seed are the same with names as without. `tests/names.js` holds the guard: `tests/names-layout.json` is the frozen record of all three at tick 0 and at day 70, and it also fails if a blessing moves the soak golden's `beings` or `items`. Only the chronicle may ever be blessed. Nothing in `names.js` may call `rng`, `rint`, or `shuffle`.
- **The lost people.** At generation a syllable tongue is built, 8 to 12 onsets, 5 vowels, 6 to 8 codas, with forbidden pairs so words stay sayable. `nameTheLand()`, called from `startWorld` after `generate()` returns, builds the mythos and puts old names on every hill, cave, and grove, on the river, and on one crossing in three. Every old name carries a meaning from `LAND_WORDS`, and a meaning is never used twice. A name with no meaning left is not given at all.
- **Learning.** An old name is unknown until somebody stands on the thing or draws the water. Then the whole world knows it, and the chronicle says what it means. Until then the interface says `the hill east of Reedwater`, through `describe`.
- **The namer.** `nameThing` gathers candidates from the land, the recent events, the notable people, the learned old names, and the mythos, weights each axis by one trait of the namer from 0.7 to 1.3, and takes the top. A text another thing already owns scores zero. The namer is the most sociable living member at the place.
- **The moments.** A camp takes the founder's name when the site is chosen, its own name when the hearth has burned three days, and a last look at its name when it becomes a village, where the name it has is a candidate at 60. After that `rename(camp, record)` is the only door, and it takes a reason. A sector is named by the first camp member to finish work in it, a pond by the first person to drink from it, the valley by the first village. Events are named at the fire the next night, and `eventName(entry)` keeps the phrase the same everywhere.
- **Epithets.** Everyone earns one after ten days in a camp, scored from what peers think, from the tags on their own history, from their life, and from their birth. The camp is the namer, so no trait weight applies. A later candidate must score half again as much to replace the one held. Fate gives the last one at death. `fullName(a)` is what the interface shows. An epithet is not a place, so it never has to be unique.
- **Two data stamps.** A chronicle line carries a `tag` and the id of the camp it belongs to. The event table and the epithet's deeds read the tag; nothing reads text. `a.diedAt` is the tick of death.
- **The nightly pass.** `nameTick()` is the last statement of `updateCamps`. It runs at 20:00 and names camps, villages, events, and epithets. `updateWorld`'s order in `main.js` is untouched, and the world stream's order cannot move, because the pass draws from the name stream alone.
- **Seeds, not built.** `rename` with a reason is the one door conquest would use. The `lineage` record and the birth source on epithets are what nobles would read. Named events are the raw material for tales told by the fire. No rule opens any of them yet.
```
